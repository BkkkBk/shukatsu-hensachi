# 就職偏差値検索

日本企業の就職偏差値を検索できる、単一ファイルの静的Webツール（`偏差値検索.html`）です。
依存ライブラリなし。ブラウザで開くだけで動きます。

## 特長

- **2つのランキングをタブで切替**
  - **総合ランキング** … 日本企業500社超
  - **IT業界** … 3つのIT就職偏差値ソースを統合（287社）
- **柔軟な検索**
  - 社名・英語名・**ローマ字**（`sony`→ソニー）・**ひらがな/カタカナ**自動変換
  - スコアリング順表示（完全一致 > 前方一致 > 部分一致）
- **偏差値での検索**… `67` で単一値、`55-60` で範囲（全角・逆順もOK）
- **偏差値帯ごとの色分けバッジ**
- 一部のIT企業は推敲による暫定値で、**`仮` タグ**を表示

## IT表の作り方（較正）

3ソース（reashu.com / corp-ratings.com / note.com）はスケールも表記もバラバラなため、
次の手順で1つの絶対スケールに統合しています。

1. 各ソースを「総合表に実在する共通企業」で線形回帰し、総合スケールへ較正
2. 表記ゆれを名寄せ（例: 日本オラクル＝日本Oracle＝Oracle）
3. 全社、複数ソースの較正値の平均で決定（**IT企業間の相対序列を優先**）

> ここでの「偏差値」は**入社難易度・水準（ブランド/市場評価）**の指標であり、
> 年収・ホワイト度などの待遇は含みません。

## 使い方

`偏差値検索.html` をブラウザで開くだけです。
